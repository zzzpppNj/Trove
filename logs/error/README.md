# 错误日志

Agent 在执行过程中遇到错误或异常时，在 `logs/error/` 记录一条日志，文件名 `YYYY-MM-DD-HHMMSS.md`。

## 何时记

- 采集失败、浏览器接管失败、页面解析失败、脚本报错、`git commit` 失败等任何未按预期完成的情况。

## 字段

- 时间：发生时间
- 来源：自动化 id 或「手动」
- 任务：正在执行的任务
- 现象：发生了什么
- 根因：如能判断，写判断依据
- 影响：数据/工作区的实际影响
- 处理：已尝试的修复与待办

## 示例

```markdown
- 时间：2026-10-26 21:00
- 来源：trove
- 任务：每日全量选品采集
- 现象：cua.getState 无法列出 Chrome 标签页
- 根因：Mac 锁屏，原生应用清单不可用
- 影响：本轮采集未产出数据
- 处理：提示用户解锁 Mac，下轮重试
```

## 规范

- 手机号、地址、密码、验证码等敏感信息必须脱敏，不写入日志。
- 记录后如有需要，随工作区变更一起 commit。
