# 验货与验机要点

验货的目标是把“卖家说的”变成“你能确认的”，全程保留证据。

## 交易全流程

1. 下单前：仔细看描述与实拍，索要序列号/IMEI、购买凭证、瑕疵特写；对模糊或刻意回避的细节追问到底。
2. 收货/面交时：只走平台流程；快递当面验收并录制开箱视频；面交选公共、有监控的场所。
3. 验收时：按品类做针对性检查，当场核对序列号、功能与描述是否一致。
4. 售后前：确认收货前不放松；发现问题及时拒收或申请退款，保留完整证据。

## 重点品类验机

- iPhone/iPad：用序列号/IMEI 查激活日期与保修状态，核对电池健康、是否有 iCloud 锁或监管锁；测试屏幕、摄像头、面容/指纹、通话与网络。
- 相机与镜头：查快门数，检查传感器坏点/霉点、镜头镀膜与进灰、防抖、对焦、接口是否正常。
- 显卡：核对序列号，看外观成色与散热；跑分/压力测试并留证，重点警惕矿卡。
- 笔记本：核对序列号与保修，查电池循环与硬盘健康，测试屏幕、键盘、接口。

验机方法与平台政策会更新，具体到某一型号时，以平台官方验机指南和厂家查询渠道的最新口径为准，不要凭记忆硬套。
