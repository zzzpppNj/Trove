# 识别个人卖家 vs 二道贩子

核心思路：判断的不是“他是不是贩子”这个标签，而是 **“他说的成色和来源我能不能验证”**。二道贩子不等于骗子，但他们的货往往来源不清、翻新/以次充好的概率更高；识别出来是为了决定“敢不敢信、该砍多少”。

## 对照表

| 维度 | 真实个人卖家 | 二道贩子 / 黄牛 |
| --- | --- | --- |
| 主页在售 | 品类杂：日用品、书、衣服、数码混着 | 清一色同类：整页都是手机/显卡/相机/包 |
| 在售数量 | 通常 10 件以内 | 几十上百件，连续上新 |
| 描述语气 | 口语化、具体，写得出使用细节和瑕疵 | 模板化：“99 新”“女生自用”“急用钱”“公司清仓” |
| 图片 | 随手拍、有生活背景、愿意补图 | 统一背景/白底图、角度一致，甚至多个账号同图 |
| 价格 | 定价偏随意，有高有低 | 精准卡在行情价，甚至带“已售 xx 件” |
| 来源解释 | 能说清入手渠道，拿得出订单/发票 | 含糊：“帮朋友出”“回收的一手”“公司奖品” |
| 沟通 | 能具体回答成色、序列号、维修史 | 回复套路化，答非所问或催你下单 |
| 交易偏好 | 接受面交、补视频 | 拒绝面交、拒绝视频、引导加微信 |

## 最实用的“三板斧”

1. 点进主页看 **在售 + 已售 + 评价**：整页同类、量大、好评文案雷同的，基本是职业号；“个人闲置”应该是杂货铺的样子。
2. 问三个具体问题：**“什么时候在哪买的”“有订单截图或发票吗”“有没有维修/磕碰，补个瑕疵特写”**。真实卖家能给出细节和凭证，贩子要么含糊，要么只会发“放心，没问题”。
3. 看图片和价格：多图一源、白底统一、价格精准贴着行情的，警惕值拉高；再用序列号官网可查、支持面交或验机来兜底。

## 容易踩的误区

昵称带“闲置”“自用”、芝麻信用极高、头像很生活化，这些 **都是可包装的**，只能当参考，不能当证据。真正靠得住的是“凭证 + 具体细节 + 平台内可验证”。

遇到“来源说不清、价格又低于行情 20% 以上”的，不管主页多像个人，都按贩子的货来对待——要么不买，要么按问题机狠狠砍价并走验机。
