# 谈价话术库

以下为模板，使用时结合具体商品、价格与卖家类型改写，保持口语化。

## 开场（先问，不急着砍价）

- “你好，这个还在吗？”
- “老板，这个 X 还在不？想了解下成色。”
- “你好，看到你出的 X，方便说下用多久了吗？”

## 问成色与凭证

- “方便发个瑕疵特写吗？主要想看下 X 的情况。”
- “这个用了大概多久呀？有没有修过或者磕碰？”
- “方便给下序列号吗？我想查下保修/激活日期。”
- “有购买记录或发票吗？没别的意思，就是图个踏实。”

## 首次报价（给理由）

- “如果成色跟你说的差不多，X 块能出不？我看同款最近差不多这个价。”
- “X 块出吗？因为已经过保了，后面有问题我得自己修。”
- “这个价稍微有点高，X 块自提能接受吗？我自己来拿，省得你寄。”

## 让步与还价

- “再让一点呗，X 块我今天就能定。”
- “这样，X 块，走平台我拍，成不？”
- “你也知道这玩意用久了会老化，X 块大家都省心。”

## 促成（给确定感）

- “OK 那就 X 块，我拍了，今天能发货吗？”
- “可以，走平台交易吧，我确认没问题就收货。”

## 应对拒绝 / 僵持

- “没事，那你先卖着，合适再叫我。”
- “价格上我最多到 X，你再考虑下，不急。”

## 机械 vs 口语对照

- 机械：“尊敬的卖家您好，请问此商品是否支持优惠？”
- 口语：“你好，这个能再便宜点不？”

- 机械：“经比对市场行情，贵商品定价偏高，诚心求购，能否让价？”
- 口语：“我看同款最近都这个价，能再少点不？”

- 机械：“请提供购买凭证及序列号以便核实。”
- 口语：“方便发下序列号吗？我查下保修。”

## 按卖家类型微调

- 真实个人卖家：语气更生活化，多聊使用细节，砍价幅度正常，重在建立信任。
- 二道贩子 / 黄牛：语气客气体面但直接，重点压来源不清与无凭证，按“行情价 + 风险折价”砍，并要求验机 / 面交。
